# Тестовое приложение без строки итога — провал в `scripts/test.sh`

**Статус:** принята 16.11.2026 (владелец: завести issue и сделать). Issue: #55.

## Задача

`scripts/test.sh` засчитывает тестовое приложение .NET, вышедшее с кодом 0 без строки `total:`, как прошедшее:
`ok  <приложение> — 0`, итоговый код 0. Так бывает, когда приложение не дошло до прогона или сменился формат
итога Microsoft.Testing.Platform. Тесты не шли, а прогон зелёный. Проверка «ноль тестов в сумме» ловит это, только
когда молчат все приложения сразу.

## Решения

### Нет строки `total:` — провал при любом коде

Приложение без строки итога засчитывается упавшим: `FAIL  <приложение> — код <N>, нет строки «total:»`, затем его
вывод, итоговый код 1. Код 8 («нет тестов под фильтр») — по-прежнему не провал: строки итога у него нет по
определению.

- *Почему:* так же уже устроены тесты скилла (без строки «итого» — провал при любом коде). Строка итога — то, по
  чему видно, что тесты шли.
- *Цена:* нативный обрыв (код 134, вывода нет) теперь печатает `код 134, нет строки «total:»` вместо `код 134`.
  Причина та же, приписка верна.

## Проверяемость

Автотеста нет: обвязка для `test.sh` несоразмерна (решение #44). Проверка — живыми прогонами.

## Критерии готовности слайса

1. Полный прогон с подставным приложением в каталоге сборки, которое молча выходит с кодом 0:
   `FAIL  MeetingAssistant.FakeTests — код 0, нет строки «total:»`, остальные `ok`, итоговый код 1. Без правки
   тот же прогон даёт `ok  MeetingAssistant.FakeTests — 0` и код 0.
2. `scripts/test.sh --help` (все приложения печатают справку и выходят с кодом 0 без итога): `FAIL` на каждом,
   код 1.
3. Прогон без подмены — как раньше: строки `ok`, итог, код 0.

## Границы

- Код 0 со строкой `total: 0` (приложение сказало «ноль тестов» и вышло нулём) не разбирается: Microsoft.Testing.Platform
  отвечает на это кодом 8.
- Тесты скилла не меняются.
