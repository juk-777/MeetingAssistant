# Начало встречи — с первым событием, без отдельного блока

**Статус:** принята 19.11.2026. Issue: #72.

## Задача

При первом подключении `meeting-watch` печатает блок `начало<TAB><строк>` с транскриптом до этого момента. Блок
приходит сессии уведомлением `Monitor`, у неё начинается ход, а события нет — отвечать не на что. Правило «прочитать
и ничего не писать» модель не держит: в 2 подключениях из 3 сессия пишет в чат фразу вроде «Контекст встречи
прочитан, жду событий» (нота в #72).

## Решения

### Хода без события нет

При первом подключении `meeting-watch` ничего не печатает: запоминает, сколько событий уже было (их не
повторяет), и сохраняет состояние с непрочитанным транскриптом. Первый блок события или конца записи несёт все строки
с начала встречи — по тому же правилу, что и сейчас: «все строки, которых сессия ещё не видела».

- *Почему:* текст правила уже не удержал модель ни здесь, ни в окне подсказок (#11); убрать ход — надёжно.
- *Цена:* сессия видит начало встречи не при подключении, а с первым событием. Объём тот же; до первого события
  подсказывать не по чему.
- Перезапуск `meeting-watch` до первого события строк не теряет: они ещё не прочитаны и уйдут с событием.
- `SKILL.md`: абзац про блок `начало` убирается; первый блок события — контекст встречи и само событие. Плагин — 0.3.2.

## Проверяемость

Тесты скилла: первое подключение — вывода нет; первое событие несёт все строки с начала встречи; конец записи без
событий — тоже; перезапуск до первого события — строки с первым событием, без повтора; прошлые события не
повторяются; два проекта читают независимо. Тесты синхронизируются с запуском по файлу состояния, а не по выводу.

## Критерии готовности слайса

1. Тесты скилла (WSL и Git Bash) зелёные; мутация «блок `начало` снова печатается» и «строки до подключения
   считаются прочитанными» роняют свои тесты.
2. Живая проверка (`claude -p` со скиллом из ветки, идущая синтетическая встреча, 3 подключения): ни в одном нет
   текста до первого события; на первое событие сессия видит строки с начала встречи.
3. `docs/architecture.md` — вывод `meeting-watch` без `начало`; `scripts/test.sh` зелёный.

## Границы

- Строка пользователю при подключении («Подключился к встрече…», шаг 4) остаётся: её просит правило.
- Замеры в `docs/measurements.md`, где упомянут блок `начало`, — исторические, не правятся.
