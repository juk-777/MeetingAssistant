# Подсказки из общих знаний

**Статус:** принята 13.11.2026. Issue: #41. Меняет «Подсказки ведёт рабочая сессия проекта» (`docs/decisions.md`)
и правило «без источника подсказки нет» из спеки скилла (`docs/specs/2026-11-10-meeting-skill.md`).

## Задача

Скилл `/meeting` пускает только подсказку со ссылкой на код, доки, issue или память проекта: «Без источника
подсказки нет» (`SKILL.md`, «Пробуждение»). Модель отвечает и на вопрос вне проекта — бест-практики, «как лучше
сделать X», устройство чужой технологии, — но правило велит ей молчать. В каталоге без проекта подсказок нет
вовсе: ссылаться не на что.

Правило писалось против выдуманных фактов о проекте (несуществующий метод, неверное значение настройки).
Общий вопрос этим не грозит: ответ не утверждает ничего о проекте.

## Решения

### Два вида подсказки: факт о проекте и общее

- **Факт о проекте** — как сейчас: сверка чтением (`Grep`, `Read`, `gh issue view`), последней строкой — источник.
  Не нашлось — подсказки о проекте нет.
- **Общее** — ответ из знаний модели, последней строкой — `общее` вместо источника. Когда: прозвучал вопрос или
  тема, по которым «Я» полезно что-то сказать или спросить прямо сейчас, а ответ не про код и решения проекта.
  Модель не уверена — молчание: подсказка, которой нельзя верить, хуже тишины.
- **Чтение — по делу, коротко.** Общий вопрос, к которому в проекте есть что добавить («что такое outbox»,
  а outbox в проекте есть), — общий ответ и строка о том, как у нас, со ссылкой. Чтение — `Grep` по ключевому
  слову и `Read` найденного места, без обхода репозитория: подсказка нужна, пока о вопросе ещё говорят.
- *Почему пометка:* общий ответ проверять негде, а пометка `общее` говорит «Я», что это знание модели, а не факт
  из репозитория — и в терминале, и в `hints.md`.
- *Цена:* больше подсказок на рабочей встрече — каждая видна поверх звонка. Удерживает правило «полезно прямо
  сейчас»; доля молчаний по `hints.md` покажет, не стало ли шумно (#3).

### Сессия — в любом каталоге

Скилл не требует репозитория: в каталоге без проекта остаются только общие подсказки. `SKILL.md`, README
и `docs/architecture.md` перестают обещать «сессию проекта» как условие.

### Версия плагина 0.2.6

Правка скилла едет с подъёмом версии, тег — сразу после слияния.

- *Цена:* у кого приложение 0.2.5, скилл 0.2.6 предложит обновить приложение (код 4, около 53 МБ), хотя
  в приложении ничего не менялось: сверка версий — по номеру, отдельной минимальной версии приложения нет
  (`docs/decisions.md`, «Приложение старее плагина — отказ до окна»).

## Проверяемость

Скрипты скилла не меняются — автотестов на правило нет, оно проверяется прогоном сессии без звука: `claude -p`
со скиллом из рабочей копии, каталог встречи собран руками — транскрипт с общим вопросом, вопросом о проекте
и фразой без вопроса, `events.log` с событиями и `конец записи`. Ожидание: на общий вопрос — подсказка
с последней строкой `общее`; на вопрос о проекте — подсказка со ссылкой; на фразу без вопроса — молчание. Сессия —
в каталоге репозитория и в каталоге без проекта (там на вопрос о проекте — молчание или `общее`, но не выдуманная
ссылка).

Скорость — по тому же прогону, замером, без порога: задержка «событие → подсказка» (`hints.md`) по частям —
доставка события сессии, ход модели, вызовы инструментов (`stream-json`); на тех же вопросах — Sonnet и Opus.
Итог — в `docs/measurements.md`, что брать для встречи — в README. Вопрос о проекте без сверки
(ссылка без чтения) — провал.

Живая проверка — у владельца: созвон с общим вопросом, подсказка `общее` в уведомлении.

## Критерии готовности слайса

1. `SKILL.md`: два вида подсказки, сессия без проекта; `description` — без «только с источником».
2. README, `docs/architecture.md` («Ответ»), `docs/decisions.md` — описывают общий вид подсказки.
3. Прогон без звука по «Проверяемости» в обоих каталогах — виды подсказок и задержка по частям на Sonnet
   и Opus; итог в плане и `docs/measurements.md`, совет по модели — в README.
4. Плагин 0.2.6, тесты скилла зелёные в WSL и Git Bash.

## Границы

- Режим собеседования (контекст встречи, роли, экран, разбор задачи на онлайн-кодинге, протокол) — #11.
- Приложение записи не меняется: поводы пробуждения те же.
