## 1. Стенд молчания

`prototype/candidate_dash.sh`: три случая, где последняя реплика «Собеседников» — речь самого кандидата
(оборванная, законченная, с заминкой), и контроль — явный вопрос интервьюера. Каждый прогон — `meeting-candidate` на
новой встрече, ответ — из `candidate.md`; сбои модели считаются отдельно. Третий аргумент — каталог скриптов другой
редакции, чтобы сравнить с `main`.

**Готово, когда:** на `main` стенд воспроизводит дефект — пояснения вместо «-».

*Подтверждено:* на `main` — 6 пояснений из 30 случаев речи кандидата, все по-английски. Найдено и исправлено: стенд
ждал приветствия окна по выводу прошлого прогона (гонка перенаправления фоновой задачи) и гонял холостые прогоны на
пропавшем каталоге скриптов — теперь отказ.

## 2. Правила роли — системным промптом

`meeting-candidate`: роль, контекст, заметки и правила ответа — файлом `--system-prompt-file`, один раз на окно; на
вход — последние строки и реплика. В правилах: отвечать только по-русски; речь кандидата — тоже «-»; «-» без
пояснений.

**Готово, когда:** тесты скилла зелёные в WSL и Git Bash; мутант «снят `--system-prompt-file`» роняет тест контекста
и заметок; в Git Bash настоящий `claude.exe` читает файл по пути MSYS.

*Подтверждено:* WSL — 116 тестов, 0 упало; Git Bash — 84, 0 упало; мутанты «снят флаг», «`write_rules` не вызывается»,
«правила пустые», «заметки не в правилах» роняют `candidate_WhenModeAndNotesGiven_PassesModelContextAndNotes`; в Git
Bash окно ответило по заметкам из системного промпта. Текст правил для модели тестом не закреплён — его держит стенд.

## 3. Замер и доки

Строки таблицы — одной версией стенда: `main`, новые правила поверх системного промпта Claude Code
(`--append-system-prompt-file`), свой системный промпт. Задержка Opus — `candidate_latency.sh`.

**Готово, когда:** на ветке «-» на речь кандидата во всех прогонах и ответ на вопрос по-русски во всех; таблица и
решение — в `docs/measurements.md` и `docs/decisions.md`.

*Подтверждено:* «-» на речь кандидата — 24 из 30 (`main`), 27 из 30 (поверх умолчания), 30 из 30 (свой системный
промпт); ответ на вопрос по-русски — 10 из 10 везде. Задержка Opus — первый символ 1.4–3.1 с, медиана 1.5.
