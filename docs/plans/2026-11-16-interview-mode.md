# План: режим собеседования, слайс 1 — роль кандидата с быстрой подсказкой

**Статус: закрыт 16.11.2026.** `--mode candidate`: окно подсказок отвечает потоком на каждую реплику собеседников —
первый символ через 2.2 с после строки транскрипта (Opus, медиана), около 3 с после конца реплики вживую; сессия
не дублирует подсказки, пишет протокол собеседования. Плагин 0.2.11.

Спека: `docs/specs/2026-11-16-interview-mode.md`. Issue: #11. Кода в плане нет — он в репозитории.

## 1. `meeting-candidate`

*Подтверждено:* 8 тестов на двойнике `claude` (поток `stream-json` с паузами, двойник `powershell.exe` читает stdin,
как настоящий). Мутации: снят фильтр канала — падает тест «реплика «Я» и короткая — без вызова»; снят обрыв прошлого
ответа — тест обрыва; снято уведомление — тест уведомления; снят `< /dev/null` у уведомления — тест журнала
(текст ответа теряется).

## 2. Режим при старте

*Подтверждено:* 7 тестов `mode_`/`linuxmode_`/`modegitbash_` (двойники `powershell.exe` и эмулятора). Мутации: имя
дистрибутива не передаётся, кавычки в контексте не экранируются — падают свои тесты. Перебор эмуляторов Linux вынесен
в `linux-terminal`, тесты окна записи `linuxstart_` зелёные без правок. Вживую (Windows из WSL): окно открывается с
путём встречи с кириллицей, пробелами и «ёлочками»; имя дистрибутива в кавычках `wsl.exe` не находил — исправлено.

## 3. Правила скилла

*Подтверждено:* `SKILL.md` — шаг «Режим» при подключении, абзац «Режим кандидата» у пробуждения, протокол
собеседования. После слияния #58 правила подсказки сведены с карточкой (конфликт при пересадке ветки — вручную).
Живая сессия `/meeting start … --mode candidate` (с открытием окна записи и захватом звука) не прогонялась: окно,
режим и быстрый путь проверены по частям ниже.

## 4. Замер и живая проверка

*Подтверждено:*
- `prototype/fast_hint.sh` и `prototype/candidate_latency.sh` — таблицы в `docs/measurements.md`, «Подсказка
  кандидату: быстрый путь»;
- `meeting replay` синтезированной речи «интервьюера» (голос Windows, 72 с) с `meeting-mode` на встрече: окно
  ответило на 3 вопроса, пропустило реплики короче 3 слов, закрылось после конца записи;
- найдено на живых прогонах и исправлено: уведомление съедало куски ответа (наследовало его поток), конец записи,
  дописанный вместе с последней строкой, терял эту строку (в Git Bash — в 1–3 тестах из 8 на прогон; после правки
  Git Bash 4 прогона подряд зелёные). Первый живой прогон через `replay`, где окно не ответило вовсе, повторить не
  удалось — вероятно, та же гонка.
