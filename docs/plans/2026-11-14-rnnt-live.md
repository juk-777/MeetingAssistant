## 1. Опорный прогон

`meeting replay samples/call1.wav --speed 10` сборкой Release из `main` (CTC), под `/usr/bin/time -v`: итоговая
строка (строки, события, фраза p50/p90/max, CPU), пик памяти, транскрипт и события — для сравнения в этапе 3.

*Подтверждено:* 66 строк, 16 событий, фраза 0.24 / 0.93 / 1.20 с, CPU 57.5 с, 508 МБ.

## 2. Распознаватель

`GigaAmSpeechRecognizer` — transducer (кодировщик int8, декодер, joiner), `modified_beam_search` на 4 пути. Файлы
модели — `SpeechModels`, проверка на старте — та же. Модель со сверкой SHA-256 — в обоих скриптах.

**Готово, когда:** интеграционные тесты распознавания зелёные на RNNT; мутант «другой каталог модели» и «жадный
поиск вместо beam» — видны (первый тестом, второй — прогоном); инспекция чистая.

*Подтверждено:*
- `scripts/test.sh` — 257 тестов зелёные, в том числе распознавание образца речи на RNNT.
- Тест скилла сверяет каталог и файлы модели в `SpeechModels`, `install.ps1` и `download-models.sh`: CI ставит
  модели вторым скриптом, и расхождение с первым иначе не видно. Мутанты «нет joiner в `install.ps1`» и «другой
  каталог в `download-models.sh`» тест роняет.
- Новый тест: отказ на старте называет недостающий файл модели — кодировщик, декодер, joiner или токены. Мутант
  «joiner не проверяется на старте» тест роняет.
- Жадный поиск вместо beam тестом не ловится. Его видно прогоном: вывод `replay` совпадает с прототипом на beam
  на 0.993, с жадным — на 0.982.
- `scripts/inspect.sh` — 0 предупреждений. Тесты скилла: WSL — 69, Git Bash — 67 (до нового теста), упало 0.

## 3. Сравнение

Тот же `replay` сборкой ветки; разница по словам — `difflib` по транскриптам. Записи с машины владельца — `meeting
replay` на Windows прежней и новой сборкой, только числа. Установка — `install.ps1 -FromSource` поверх прежней.

*Подтверждено:* `docs/measurements.md`, «Живое распознавание: RNNT против CTC».
- CTC — установленная `v0.2.5`: код распознавания в ней тот же, что в `v0.2.6`.
- Установка `-FromSource` на машине владельца не запускалась. Она заменяет его рабочее приложение и переменные
  пользователя, поэтому без его слова её не делаю. Расходится с критерием спеки — вопрос владельцу. Предложение:
  проверка — его обновление до `v0.2.7` после тега: тот же путь «поверх прежней», что у пользователей.
