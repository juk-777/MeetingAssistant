## 1. Каталог встречи и слежение за событиями

`skills/meeting/scripts/`:
- `meeting-dir` — каталог встречи из аргумента или `$MEETINGS_ROOT/current.json`, перевод пути Windows;
- `meeting-watch` — первое подключение, событие с новыми строками, конец, состояние чтения на пару «встреча,
  проект».

Тесты — bash-сценарии в `skills/meeting/tests/`, `scripts/test.sh` запускает их и учитывает в сумме.
`scripts/slnx-folders.sh` раскладывает и `skills/`.

**Готово, когда:** тесты закрывают свойства спеки о чтении и путях. Ручные мутации, каждую ловит свой тест:
- снят учёт отданных событий;
- неполная строка отдаётся;
- выход на конце снят;
- перевод пути снят.

*Подтверждено:* 12 тестов скриптов, `scripts/test.sh` учитывает их в сумме. Ручные мутации, каждую убил свой тест:
- первое подключение отдаёт прошлые события;
- состояние не сохраняется — оба теста перезапуска;
- неполная строка отдаётся;
- выход на конце снят;
- ключ состояния без проекта;
- перевод пути снят — оба теста пути Windows.

## 2. Журнал пробуждений

`skills/meeting/scripts/meeting-hint` дописывает строку в `hints.md`.

**Готово, когда:** тест закрывает формат: склейка строк, табуляции, молчание. Мутация «склейка снята» убита.

*Подтверждено:* 3 теста формата. Мутации «склейка снята», «табуляции не заменяются», «молчание не помечается» —
каждую убил свой тест.

`skills/meeting/SKILL.md`:

`scripts/install-skill.sh` ставит ссылку. Раздел 2 `docs/architecture.md` — по фактическому поведению.

**Готово, когда:** установка на пустой каталог ставит ссылку, повторная ничего не ломает, занятый чужим каталогом
путь не перезаписывается.

*Подтверждено:* 3 теста установки в отдельном каталоге настроек (`CLAUDE_CONFIG_DIR`). Мутации «чужая ссылка
принимается», «занятый путь не проверяется», «ссылка не ставится» — каждую убил свой тест. Правила `SKILL.md`
кодом не проверяются — их проверяет живой прогон (этап 4).

## 4. Живой прогон

`meeting replay` записи созвона идёт Windows-процессом. Сессия в WSL открыта отдельно в другом проекте:
- `/meeting` подключается с чистого листа;
- `Monitor` для прогона ставится на 3 минуты;
- после конца встречи — `/meeting протокол`.

**Готово, когда:** критерии 2–3 спеки подтверждены по `hints.md`, `transcript.md` и `protocol.md`, числа —
в `docs/measurements.md`.

*Подтверждено:* `docs/measurements.md`, «Скилл `/meeting` на живом прогоне».
- На каждое событие после подключения — одна строка `hints.md`; транскрипт отдан целиком. Два события
  до подключения пришли блоком `начало`; критерий 2 спеки уточнён так по решению мейнтейнера.
- Три перезапуска `Monitor` по истечении прошли без потерь; после конца записи перезапуска нет.
- Медиана задержки 4.5 с, max 25.4 с; молчаний 67 %.
- Протокол со всеми четырьмя разделами.

По журналу сессии: `PushNotification` вызван на 1 подсказке из 5 — сессия перестала его вызывать после ответа
«not sent». Правило в `SKILL.md` уточнено. Доходит ли уведомление при неактивном терминале, не проверено.

## 5. Закрытие

Критерии готовности спеки — по списку, у каждого записано, чем подтверждён. Мутации, саморевью, ретро, ревью
мейнтейнера, пуш. После пуша — нота в #2, #2 закрыт, галка в #1 не ставится: #2 — отдельная часть, не слайс #1.

*Подтверждено:* критерии спеки:

2. Живой прогон — этап 4.
3. Протокол — этап 4.
4. Тесты установки, в том числе по пути через ссылку.

Саморевью — независимый агент. Находки починены в этом слайсе. Переводы строк скриптов в клоне Windows вынесены
в #9.

## 6. Уведомление Windows

Повторный прогон показал: `PushNotification` отвечает «Terminal notification sent», а Windows Terminal ничего
не показывает. Решение мейнтейнера — `skills/meeting/scripts/meeting-notify`: уведомление Windows через
`powershell.exe`, на каждую подсказку вместе с `PushNotification`. Спека, `docs/architecture.md`,
`docs/decisions.md` — тем же проходом.

**Готово, когда:** тесты закрывают передачу текста и выход без `powershell.exe`, мутации убиты; показ
с кириллицей и кавычками подтверждён вручную.

*Подтверждено:*
- 4 теста, всего 28 тестов скриптов. Мутации «WSLENV снят», «WSLENV перезаписывается», «разделитель WSLENV
  всегда», «текст не экспортируется», «`\r` не снимается», «склейка строк снята», «выход без `powershell.exe`
  снят» — каждую убил свой тест.
- Живой прогон: 4 подсказки — 4 уведомления на экране, кириллица читается (`docs/measurements.md`).
- Длинный показ (`duration="long"`) кодом не проверяется — только глазами.
- Вручную: уведомление показывает заголовок и 4 строки текста, около 180 знаков, остальное обрезает. Поэтому
  суть для уведомления в `SKILL.md` — до 150 знаков.
