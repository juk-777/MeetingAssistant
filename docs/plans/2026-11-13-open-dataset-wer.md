## 1. Подготовка набора

Скрипт в `prototype/`:
- распаковывает архив части OpenSTT из `samples/openstt/`;
- делает выборку фраз с зерном 35 до 3600 с;
- режет каждую фразу Silero VAD с параметрами приложения.

Выход — каталог `seg/` того же формата, что у `bench.py`: его без правок читают `rnnt.py` и `wnet`. В
`segments.json` у отрезка — номер фразы набора, эталоны лежат рядом. Второй каталог — фразы целиком, по отрезку на
фразу: контроль без VAD.

**Готово, когда:** повтор даёт тот же список фраз; сумма речи выборки — около часа на часть.

*Подтверждено:* `prototype/openstt.py`. Фразы набора вырезаны впритык к речи, поэтому подача уточнена: одним
потоком через секунду тишины (спека, «Подача»). Повторные сборки совпадают байт в байт: звонки — 1642 фразы из
12 950, 3602 с, 1612 отрезков; YouTube — 1629 из 7311, 3600 с, 1598 отрезков. Отрезки не задели 38 и 25 фраз.
13 отрезков YouTube захватывают соседнюю фразу: Silero не закрыл их на цифровой тишине, и в счёте такая пара фраз —
одна единица. Скачивание со сверкой SHA-256 и повтор одной командой — `prototype/openstt-run.sh`.

## 2. Счёт

Скрипт в `prototype/`:
- нормализация по спеке;
- WER и CER по корпусу;
- выравнивание с разметкой ошибок, где слово гипотезы записано цифрами или латиницей;
- сопоставление строк вывода с фразами набора по времени начала: кусок turbo — несколько фраз подряд.

**Готово, когда:** проверка на известных входах из «Проверяемости» спеки проходит.

*Подтверждено:* `prototype/wer.py --test` — 12 проверок проходят. Девять мутантов на копии файла упали каждый на
своей проверке:
- без `ё` → `е`;
- без счёта CER;
- без пометки в замене и во вставке;
- дробь без дробной части;
- начало строки — предыдущий отрезок, а не ближайший;
- без слияния разрезанной фразы;
- без фразы без отрезков;
- без отрезка через границу фраз;
- без разбора строки с пустым текстом.

Проверка нашла дефект: строка вывода с пустым текстом без пробела после `]` роняла разбор.
