## 1. Подготовка набора

Скрипт в `prototype/`:
- распаковывает архив части OpenSTT из `samples/openstt/`;
- делает выборку фраз с зерном 35 до 3600 с;
- режет каждую фразу Silero VAD с параметрами приложения.

Выход — каталог `seg/` того же формата, что у `bench.py`: его без правок читают `rnnt.py` и `wnet`. В
`segments.json` у отрезка — номер фразы набора, эталоны лежат рядом. Второй каталог — фразы целиком, по отрезку на
фразу: контроль без VAD.

**Готово, когда:** повтор даёт тот же список фраз; сумма речи выборки — около часа на часть.

## 2. Счёт

Скрипт в `prototype/`:
- нормализация по спеке;
- WER и CER по корпусу;
- выравнивание с разметкой ошибок, где слово гипотезы записано цифрами или латиницей;
- сопоставление строк вывода с фразами набора по времени начала: кусок turbo — несколько фраз подряд.

**Готово, когда:** проверка на известных входах из «Проверяемости» спеки проходит.

## 3. Прогоны и числа

CTC (`ctc.py`, 2 потока) и RNNT beam (2 потока) идут по отрезкам VAD, turbo — `wnet` с `GLUE=1` и 8 потоками.
Контроль — CTC по фразам целиком. Машина без другой нагрузки.

**Готово, когда:** в `docs/measurements.md` есть таблица по спеке и сравнение с таблицей GigaAM, шапка исправлена,
в #39 — нота.
