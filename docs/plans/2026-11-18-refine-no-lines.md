## 1. Отказ

Application: `RefineMeetingHandler` после распознавания проверяет число строк; ноль — `Result.Failure` с ошибкой
`Refine.NothingRecognized` (текст — с речью в секундах), без `Complete`: черновик бросается при освобождении. Ошибка —
рядом со сценарием уточнения.

**Готово, когда:** тест Application «только пустые отрезки при речи — отказ, черновик не завершён, строк нет»
зелёный; мутация «снята проверка» роняет его; остальные тесты уточнения зелёные без правок.

*Подтверждено:* тесты «речь есть, текста нет» и «записи без речи — отказ без вызова распознавателя»; мутации «снята
проверка» (падают оба) и «отказ только при речи» (падает второй) убиты; остальные 14 тестов уточнения — без правок.
Живой `meeting refine` (сборка из ветки, WSL, turbo из `models/`) на синтетической встрече в scratchpad — 10 с
тишины, пустой `transcript.md`, `конец записи`: код 1, `Refine.NothingRecognized: Whisper не распознал ни одной фразы
(речь 0.0 с): …`, в каталоге ни `transcript.whisper.md`, ни `.part`.
