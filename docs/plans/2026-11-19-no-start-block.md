## 1. Без блока `начало`

`meeting-watch`: первое подключение — состояние `<событий сейчас> 0` без вывода. Тесты — синхронизация по файлу
состояния (`$XDG_STATE_HOME/meeting-assistant`). `SKILL.md` — абзац о первом блоке. `plugin.json` — 0.3.2.

**Готово, когда:** тесты скилла WSL и Git Bash зелёные, мутации из критерия 1 спеки роняют свои тесты.

*Подтверждено:* тесты скилла WSL — 130, 0 упало. Мутации убиты: блок `начало` снова печатается (падают 8 тестов
`watch_`), строки до подключения считаются прочитанными (падают 5).

*Живая проверка (критерий 2, Claude Code 2.1.327, Opus, effort high, скилл из ветки):* 3 подключения к идущей
синтетической встрече из 5 строк в scratchpad, 45 с без событий, затем событие `вопрос` и конец записи. Во всех
трёх до события — только ход подключения со строкой пользователю; на событие — `—`. Содержимое уведомлений `Monitor`
в `stream-json` не пишется: что первый блок несёт строки с начала встречи, подтверждают тесты скрипта. До правки на
том же стенде сессия писала фразу на `начало` в 2 подключениях из 3 (нота в #72).
